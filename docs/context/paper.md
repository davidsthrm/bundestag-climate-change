# Paper and presentation

Purpose: what has to be handed in, how it is graded, how the pages are split and when things are due.
Work items: #15 (paper), #16 (slides). `#N` = issue N of this repository.

## Format
- Paper: 8–10 pages, LaTeX in `paper/`, structured by CRISP-DM.
- Talk: 20 min, both present; slides in `slides/`.

## Required
- A research question.
- Join of a text source with a structured source.
- Comparison of methods on the same task.
- Validity via gold set (agreement reported) + error analysis.

## Grading
- Project 37 points: research question 7, data/join 7, methods 7, validity 7, report 9.
- Presentation 19 points.
